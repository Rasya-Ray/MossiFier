# Edge AI Decision Model — Starter

## Files
- `train_model.py`: creates synthetic training data, trains 3 Decision Tree classifiers, and exports `decision_model.h`.
- `synthetic_dataset.csv`: example synthetic dataset generated by the script.
- `decision_model.h`: generated C++ inference model.
- `esp32_decision_demo.ino`: Arduino IDE example that imports the header.

## Train on a computer
Install Python 3, then run:
```bash
python -m pip install numpy scikit-learn
python train_model.py
```
The script writes/overwrites `synthetic_dataset.csv` and `decision_model.h`.

## Use in Arduino IDE
1. Open `esp32_decision_demo.ino` in Arduino IDE.
2. Keep `decision_model.h` in the same sketch folder (Arduino IDE may ask to create a folder matching the `.ino` filename; put the header there).
3. Select ESP32 Dev Module and the correct COM port.
4. Select Arduino-ESP32 core 3.x because the sketch uses `ledcAttach(pin, frequency, resolution)` and `ledcWrite(pin, duty)`.
5. Upload and open Serial Monitor at 115200 baud.

## IMPORTANT limitations
- This is a software pipeline demonstration trained on synthetic labels generated by simple hand-written example rules. High test accuracy only means it learned those artificial rules; it does NOT prove real moss-health prediction or safe actuator decisions.
- The example input order is fixed: CV healthy %, CV stressed %, CV critical %, soil moisture %, MQ135 raw ADC, PMS5003 PM2.5.
- CV probabilities and PM2.5 are placeholders in the `.ino`; replace them with actual data from the separate CV system and PMS5003 UART parser.
- Soil calibration values are placeholders. Measure raw readings in dry and wet soil.
- MQ135 raw ADC is not ppm. Use calibration if you need gas concentration estimates.
- The example fan policy treats high outside PM2.5 as a reason not to bring outside air in. Confirm whether your fan is an intake/exhaust fan or just recirculating air before using it.
- Light PWM is predicted but not physically applied because the current schematic has no light driver/output pin. Add a properly rated MOSFET/driver before connecting a lamp.
- Add safety limits, pump timeout, hysteresis, sensor fault detection, and a manual override before running unattended.
